Examples

Simple leaderboard — count visits by category, refresh every 30 s

Sheet row 1:

Col A — Timestamp Col B — Category
type:timestamp|window:today type:combo|groupby|aggregate:count

URL:

display.html?sheetId=YOUR_ID&tab=Log&refresh=30

Result: one column ranked by visit count. Refreshes silently every 30 s. Refresh button hidden (TV mode).

Division leaderboard — Category × Gender, Male before Female, rank by score

Sheet row 1 (columns in order: Timestamp, Name, Category, Gender, Score):

Timestamp Name Category Gender Score
type:timestamp|window:today type:text|groupby type:combo|splitby:1 type:combo|splitby:2|order:Male,Female type:number|aggregate:sum

URL:

display.html?sheetId=YOUR_ID&tab=Log&refresh=30&cols=2

Result: columns like Open Male · Open Female · Advanced Male · Advanced Female … showing names ranked by total score. 2 columns visible at a time, pages auto-cycle every 10 s.

Stats view — totals and distributions for the current month

Sheet row 1:

Timestamp Category Score
type:timestamp|window:month type:combo|aggregate:distribution type:number|aggregate:sum|aggregate:avg|aggregate:max

URL:

display.html?sheetId=YOUR_ID&tab=Log&mode=stats

Result: stat cards showing sum / avg / max score for the month, plus a distribution panel with visit counts per category.

TV / kiosk mode

TV mode is activated automatically by adding ?refresh=N to the URL — there is no separate toggle. When refresh is present:

  • All interactive controls are hidden (no Refresh button, no autorefresh toggle)
  • Data re-fetches silently every N seconds in the background
  • A small "Last updated" indicator appears in the bottom-right corner
  • If the sheet has division columns (splitby), pages cycle automatically every 10 s (override with ?cycle=N)

To switch back to standard interactive mode, simply remove ?refresh from the URL. Standard mode shows a Refresh button and a manual autorefresh toggle.

TV on wall, refresh every 30 s, division pages every 8 s:

display.html?sheetId=ID&tab=Log&refresh=30&cycle=8&cols=2

Same URL for a phone or desktop (manual controls, no auto-cycle):

display.html?sheetId=ID&tab=Log&cols=2

Sheet config flags

Set in row 1 of your sheet. Each cell holds pipe-separated flags for that column, e.g. type:combo|groupby|aggregate:count

Flag Requires What it does
Column type — always first
type:timestamp—Datetime column — drives time-window filtering and "last seen" timestamps
type:text—Plain text
type:combo—Dropdown / fixed values
type:number—Numeric — required for sum/avg/min/max aggregates
type:desc—Column value shown as markdown description below the page heading
type:help—Column value shown in the ? help side panel (markdown)
Leaderboard — what to group and rank by
groupbyany typeGroup rows by unique values in this column. Each unique value becomes a ranked row.
groupby:Nany typeSame, with explicit column display position (1 = leftmost)
aggregate:countany typeRank by number of rows per group (e.g. total visits)
aggregate:sumtype:numberRank by sum of a numeric column (e.g. total score)
aggregate:avgtype:numberRank by average
aggregate:min / maxtype:numberRank by minimum or maximum value
Stats mode — scalar cards per column
aggregate:firstanyShow the earliest entry value
aggregate:lastanyShow the most recent entry value
aggregate:distributiontext/comboShow a frequency count panel — how many rows have each unique value
Division mode — combine two columns into compound columns
splitby:1any typeOuter division axis (e.g. Category). Combined with splitby:2 to form columns like "Open Male".
splitby:2any typeInner division axis (e.g. Gender). Order: splitby:1 value cycles once per splitby:2 value.
order:val1,val2,…splitby colFix the order of values for that axis. Unlisted values are appended alphabetically at the end.
Layout & filtering
window:Xtype:timestampTime filter applied before all aggregation — see values below
maxcols:Nany cellMaximum columns shown at once (can be overridden by ?cols=N in the URL)

Time window values

Use in the sheet flag window:X on a type:timestamp column, or override per-URL with ?window=X.

Value Meaning
todayFrom midnight today to now
monthFrom the 1st of the current calendar month
yearFrom 1 Jan of the current year
7d · 14d · 30dRolling N days back from now (replace N with any number)
2w · 4wRolling N weeks (replace N with any number)
3m · 6mRolling N calendar months
1y · 2yRolling N years
2026-01-01From that specific date to today (inclusive)
allNo filter — use all rows in the sheet
